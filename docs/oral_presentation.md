# December 10 project introduction

One member presents the project in up to five minutes. Use one example image and a simple overlay to explain the idea. Submit the slide file to Moodle as required by the course.

## Team and question

Introduce both team members and their proposed roles. State the question in plain language: can we estimate the height of a vertical object in a photograph if a second object's actual height is known?

## Example and method

Show a photograph or a diagram with a known reference and a target at a different depth. Label the ground-plane directions, the reference, and the target. Explain that a farther object occupies fewer pixels, then show how the vanishing geometry transfers the reference scale to the target's location.

Show the planned automatic mode in one diagram. The software identifies the printed tags, uses them to find the ground directions and endpoints, then outputs a height, an overlay, and a quality reason. The prepared scene includes a reference object of known height. Mention manual and assisted modes as alternatives for unmarked images.

## How the result will be evaluated

Introduce the synthetic geometry checks, public examples with documented measurements, and a small reserved set of tripod photographs. Compare raw pixel ratios, manually annotated geometry, and automatic measurement on the same prepared targets. Explain that the evaluation will record accuracy and how often the software can finish without a correction. Label illustrative numbers as examples and measured numbers with their source.
